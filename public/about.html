KhmerProof ពិនិត្យអ្វីខ្លះ

KhmerProof ពិនិត្យអត្ថបទជាស្រទាប់ៗ៖ (១) ការអ៊ិនកូដយូនីកូដ (២) ការបំបែកពាក្យដោយមិនបំបែកព្យាង្គ (៣) ការផ្ទៀងផ្ទាត់ជាមួយវចនានុក្រម (៤) អក្ខរាវិរុទ្ធ (៥) វេយ្យាករណ៍ និងរចនាសម្ព័ន្ធល្បះ (៦) វណ្ណយុត្តិ (៧) ការជ្រើសរើសពាក្យតាមប្រភេទសំណេរ (៨) ភាពស៊ីសង្វាក់នៃពាក្យបច្ចេកទេស។ ការពិនិត្យបរិបទដោយ AI ជាជម្រើស ហើយបិទតាមលំនាំដើម។

ប្រភព

  • វចនានុក្រមខ្មែរ សម្ដេចព្រះសង្ឃរាជ ជួន ណាត (វិទ្យាស្ថានពុទ្ធសាសនបណ្ឌិត ១៩៦៧) កំណែឌីជីថលរបស់វិទ្យាស្ថានបើកទូលាយ (Open Institute, កម្មវិធី SPICE) អាជ្ញាប័ណ្ណ LGPL-2.1 — github.com/interscript/khmer-dict-spice
  • បញ្ជីពាក្យ SBBIC សម្រាប់ពិនិត្យអក្ខរាវិរុទ្ធ (ក្នុងឃ្លាំងដដែល)
  • បញ្ជីពាក្យទំនើប ពាក្យច្បាប់ ឈ្មោះ និងកំហុសញឹកញាប់ ដែលគម្រោងរៀបចំ (ត្រូវការការពិនិត្យដោយអ្នកជំនាញភាសា)
  • ពាក្យបច្ចេកទេសរបស់ក្រុមប្រឹក្សាជាតិភាសាខ្មែរ (NCKL) — អ្នកប្រើអាចនាំចូលបាន។ កំណែនេះមិនទាន់មានបញ្ជី NCKL ភ្ជាប់មកជាមួយទេ។
  • ពុម្ពអក្សរ Noto Sans Khmer (SIL Open Font License)

In English

KhmerProof checks Khmer text with a layered engine built on the Chuon Nath Khmer Dictionary (Open Institute digital edition, LGPL-2.1) and the SBBIC word list. Grammar rules are project-authored and have not yet been verified against the user's grammar textbook. Confidence values are rule estimates. Text is checked in the browser and leaves it only when you consent to server PDF generation, PDF text extraction or the optional AI review. See docs/EVALUATION.md in the repository for measured results.
