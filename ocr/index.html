Khmer PDF OCR · ស្រង់អត្ថបទពី PDF

Reads Khmer and English PDFs in your browser. It uses the file's own text layer where there is a sound one, and Tesseract OCR where the text layer is missing or comes back broken — as it does in many Khmer PDFs, whose shaped glyphs map back to nothing. A page set in a pre-Unicode font — Limon, ABC, Khek and the rest — is converted byte for byte into Unicode instead, which is exact where OCR only guesses. The result keeps the page's form — alignment, indents, type size, bold, underline, Muol headings, lists and tables — and downloads as a Word file or as Markdown. Nothing leaves your machine except the one-time download of the OCR engine and language data.

OCR is a starting point for transcription, never a source to quote. Khmer OCR commonly loses a coeng or a vowel sign — read the page image beside the text before you rely on it. The engine (Tesseract.js, Apache-2.0), the rendering library (PDF.js, Apache-2.0) and the legacy-font converter (khmer-unicode-converter, LGPL-2.1, a port of the Khmer Software Initiative's KhmerConverter) are fetched from a CDN on first use; the PDF itself is read locally and never uploaded.
